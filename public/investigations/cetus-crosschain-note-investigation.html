Cetus cross-chain note (Sui)

Wiki id cetus-sui-exploit-may-2025-see-also · Live incident page

Omit from Solana totals. Cetus is a Sui (and Aptos) CLMM exploit. There is no Solana drain hashed here. Do not add ~$223M to Solana loss rollups.

Summary

Cetus on Sui lost on the order of $223M. This wiki entry exists as a see-also (Crema team lineage / CLMM patterns), not as a Solana incident.

On-chain evidence

Coverage gap / no Solana drain. No Solana collector, program, or signature. Sui hashes are out of scope for this Solana draft set.

Arkham Intel API labels Ethereum 0x0251536bfcf144b88e1afa8fe60184ffdb4caf16 as “Cetus Hacker”. That is an entity label, not a Solana hop; no Etherscan hash from the official Cetus posts is imported into on-chain evidence. Omit from Solana totals.

Root cause

Sui CLMM overflow / check issues as reported by Sui-side post-mortems. Not a Solana runtime or program bug.

Response

Cetus paused and later restarted on Sui after recovery work. Irrelevant to Solana validators.
