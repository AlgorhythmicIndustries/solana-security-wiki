Allbridge Core flash-loan

Wiki id allbridge-core-flash-loan-jul-2026 · Live incident page

Summary

A Kamino flash loan of ~1.122M USDC funded USDC/USDT swaps that skewed Allbridge Core’s Solana pool math. The attacker withdrew liquidity at the distorted rate, repaid the loan in the same transaction, and kept ~$1.65M reporting (PeckShield / Allbridge). This is a pool-swap manipulation, not a forged bridge mint.

Unverified CertiK dests without those hashes are not hops.

Root cause

Withdrawal / swap pricing derived from pool balances a single flash-loaned transaction can move. Same class as Allbridge’s 2023 BNB-chain pool incident.

Response

Core paused; LPs urged to withdraw. Allbridge asked arbitrageurs who caught the imbalance to return funds to the recovery address. Later reporting said Core resumed with CCTP / LayerZero and without the manipulated pools.
