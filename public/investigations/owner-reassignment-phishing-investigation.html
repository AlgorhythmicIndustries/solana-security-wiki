Owner-field phishing

Wiki id solana-owner-field-phishing-late-2025 · Live incident page

Summary

Late-2025 phishing on Solana used transactions that look harmless in simulation but reassign SPL / token-account owners (or other authorities). This is a pattern campaign, not a single protocol drain. Public reporting cites individual victims above $3M; there is no one collector or program that sums the class.

On-chain evidence

Coverage gap. No single drain signature, collector, or program is hashed here. The class is many victim-signed Assign / SetAuthority transactions, so a rollup hash would be invented. Do not add this wave to a Solana protocol-loss total without a per-victim signature list.

Root cause

Wallet simulation often previews net token movement and misses owner or authority changes. Users signed txs that transferred control of existing accounts rather than transferring tokens in the preview.

Response

Wallet vendors and researchers published pattern warnings. There is no protocol pause or treasury reimbursement for the class as a whole.

Coverage gaps

  • No canonical drain tx or collector for the Oct 2025 wave.
  • Aggregate USD remains unhashed; wiki lists loss as unclear.
