@solana/web3.js npm

Wiki id solana-web3js-supply-chain-dec-2024 · Live incident page

Summary

Compromised npm publish token shipped backdoored @solana/web3.js 1.95.6 and 1.95.7. Malware exfiltrated key material. Collector FnvLGtucz4E1ppJHRTev6Qv4X7g8Pw6WPStHCcbAKbfx is cited with 676.38 SOL across 46 inflows. Those 46 signatures are not enumerated in this draft.

On-chain evidence

Collector FnvLGtucz4E1ppJHRTev6Qv4X7g8Pw6WPStHCcbAKbfx. Advisory GHSA-jcxm-7wvp-g6p5. C2 domain reported as sol-rpc.xyz.

Coverage gap. The 46 inflow signatures that sum to 676.38 SOL are not listed. RPC history for this collector is larger than 46 in a Dec 3–6 window; do not substitute an unverified subset.

Root cause

Phished npm publish token; malicious postinstall / injected code in 1.95.6/1.95.7.

Response

Versions yanked; GHSA published; downstream lockfile upgrades.
