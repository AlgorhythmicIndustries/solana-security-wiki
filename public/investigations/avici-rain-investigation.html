Avici / Rain card-contract drain

Wiki id avici-rain-card-contract-aug-2026 · Live incident page

Live page already has a writeup. This draft is the IR companion. It does not add a conflicting drain-tx list: the live article describes the same Rain authorization path and refunds. Individual WithdrawCollateralAsset signatures are not hashed here.

Summary

On 28 Aug 2026 an attacker exploited an authorization flaw in an outdated Rain Solana card contract used by Avici, Tria, Solayer Pay, and other neobanks. Avici reconciled $500,859.22 across 1,685 users; Tria reported ~$431,945 across 636 users; on-chain observers estimated ~$1.1M bridged off Solana. Rain and the platforms refunded card balances (Avici/Tria added 10% cashback). A parallel wallet-drainer phishing campaign (getavici.today, ~$600K reporting) is a separate vector and is not in the $1.1M figure.

On-chain evidence

Attacker seed FVNFzqAny8spWdPmYw6RQ9TkYa29ueFFiqCFD1gQnCEj was created 28 Aug 2026 ~13:40 UTC and funded with ~1.79 SOL (~$190) via deBridge, then first hit card contracts ~16:49 UTC (Nikita / @0xVishnya timeline, Our Crypto Talk, Crypto Times).

Repeating per-victim sequence: SubmitSignatures with the Ed25519 precompile, AddCollateralAdmin, then WithdrawCollateralAsset. Analysts described thousands of automated txs (one checkpoint: 14,672 signatures, 2,344 failed).

Coverage gap. No single drain signature, Rain program id, or deBridge / Tornado hop is hashed in this draft. Do not invent a canonical vault-drain tx. The live incident page already covers mechanism and refunds without a conflicting hash list.

Root cause

Signature-verification routing bug: a second Ed25519 check was bound to the first instruction, so the runtime accepted the attacker’s signature twice and admitted an unauthorized collateral admin. Shared Rain infra, not Avici’s self-custodial wallets.

Response

Rain upgraded affected contract versions. Avici filed IC3. Card-balance refunds processed; phishing drainers remain out of the protocol-loss total.
