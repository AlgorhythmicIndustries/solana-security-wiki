io.net spoof

Wiki id ionet-gpu-spoofing-apr-2024 · Live incident page

Summary

Attackers spoofed GPU worker registrations on io.net during beta. Network integrity degraded. There was no vault drain hashed for this incident.

On-chain evidence

Coverage gap / no vault drain. This is a DePIN metadata-spoofing incident, not a Solana vault theft. No drain signature.

Root cause

Worker registration trusted self-reported GPU metadata without proof-of-resource.

Response

io.net incident report (25 Apr write-up of the 18 Apr event); later attestation work.
