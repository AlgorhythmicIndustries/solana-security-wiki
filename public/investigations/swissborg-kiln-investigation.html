8 Sep 2025

SwissBorg / Kiln SOL staking

Wiki id swissborg-kiln-sol-staking-sep-2025 · Live incident page

Summary

Compromised Kiln Connect API credentials were used to bury stake-authority changes inside txs presented as routine unstaking for SwissBorg SOL Earn. Eight stake withdraws on 8 Sep 2025 12:22–12:25 UTC credited exploiter TYFWG3hvvxWMs2KXEk8cDuJCsXEyKs65eeqpD9P4mK1. Observed sum of those eight credits is 192,623.410048043 SOL. The listed figure 192,623.410088043 SOL differs by 0.000040 SOL; this draft uses the hashed withdraw amounts, not the extra 40 lamports.

Root cause

Kiln reported a GitHub token leading to a malicious Kiln Connect API payload on deactivate-stake for large positions (reporting threshold above 150k SOL). SwissBorg signed the composed unstake txs without independently decoding the extra stake-authorize instructions.

Response

SwissBorg reimbursed users from treasury. Kiln and SwissBorg published a joint statement. Integration credentials were rotated.
