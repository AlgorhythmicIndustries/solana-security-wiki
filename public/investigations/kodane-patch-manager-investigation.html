@kodane/patch-manager

Wiki id kodane-patch-manager-npm-jul-2025 · Live incident page

Summary

Malicious npm package @kodane/patch-manager (~1,500 downloads, AI-styled docs) drained Solana wallets to collector B2XwbrGSXs3LAAcqFqKqGUug5TFA1Bug2NNGH3F3mWNK. Reporting tied C2 to sweeper-monitor-production.up.railway.app.

On-chain evidence

Collector B2XwbrGSXs3LAAcqFqKqGUug5TFA1Bug2NNGH3F3mWNK. RPC replay of 28 Jul–5 Aug 2025 shows 57 positive lamport changes totaling +4.467735973 SOL (example credit 5CWVtopGc7Hi3WnpHRc89UuhjvchVNFB5k9VRJL6ZHNAf7TbLs7vuPPwVXQRQeEzxseLPaPx8RjpsFSDD4fNABVF +1.11779643 SOL). The listed window figure +4.652 SOL is not reproduced from this collector in that window.

Coverage gap. ~0.184 SOL between observed +4.467735973 SOL and the +4.652 SOL window figure. Do not invent extra inflow signatures to close it. Some collector credits are immediately forwarded (churn), so unique victim SOL is lower than gross credits.

Root cause

Typosquat / malicious dependency executed in developer or bot environments that held keys. Package has since been removed from npm.

Response

npm takedown and public write-ups. No protocol pause.
